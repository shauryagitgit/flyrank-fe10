# FlyRank FE-10 — Accessibility Audit

Mobile-first accessibility audit workspace demonstrating responsive UI, keyboard accessibility, visible focus, polite live-region updates, and before/after evidence tracking.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import this GitHub repository into Vercel and deploy with the default Next.js settings.

## Evidence
The `AUDIT.md` file contains the audit scope, changes, and a place to record the real Lighthouse/WAVE results. Replace the placeholder before/after values with actual measurements from the deployed preview before submitting to FlyRank.
